# 目标项目布局 Agent 交接说明

本文档用于将视口测试矩阵交给其他项目的 Agent，不提供通用 CSS 断点。

## 必要输入

- 视口参考：[`viewport-presets-reference.md`](./viewport-presets-reference.md)
- 目标项目源码和当前页面
- 需要验证的业务路由和页面状态
- 如有，真机截图、设计稿和现有适配问题记录

## 给 Agent 的任务边界

Agent 应先检查目标项目，再决定：

- 哪些组件需要流式宽度、分栏或容器查询。
- 断点应设在什么内容失效位置，而不是照搬设备型号或预设宽度。
- 页面是否正确处理安全区、动态视口高度、软键盘、内部滚动和固定底栏。
- 图片、Canvas、SVG 和 1 px 边框在不同 DPR 下是否清晰。
- 需要用全部 17 个视口回归，还是可以根据项目用户群建立更小的冒烟集。

## 不应直接做的事

- 不要为 17 个视口分别创建 17 个媒体查询。
- 不要通过 User-Agent 或代表机型名称切换布局。
- 不要把 PNG 物理像素当成 CSS 逻辑视口。
- 不要在没有检查目标项目内容的情况下套用通用手机/平板断点。

## 建议交付物

- 项目自身的响应式布局策略和选择理由。
- 与项目内容对应的断点或容器查询。
- 使用 Viewport Lab 生成的真实截图结果。
- 溢出、遮挡、裁切、安全区和滚动的验收结论。
- 仍需真机确认的风险清单。

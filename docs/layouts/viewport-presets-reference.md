# 多端视口预设参考

> 版本日期：2026-07-21  
> 代码数据源：`apps/web/src/config/viewport-presets.ts`

本文档是 Viewport Lab 视口测试参数的人工可读参考，可用于其他 H5 项目建立截图矩阵、适配验收集和测试配置。

## 使用边界

- 本文档定义“用哪些视口验证”，不定义项目的 CSS 断点。
- 断点、容器查询、分栏数量和元素缩放应由目标项目根据实际内容决定。
- 代表机型只是理解屏幕档位的索引，不应用于 User-Agent 判断或业务逻辑。
- Android 参数包含工程推算值，不代表对应型号的真机规格认证。

## 参数口径

| 字段                | 含义                                                                         |
| ------------------- | ---------------------------------------------------------------------------- |
| `viewport`          | CSS 布局使用的逻辑宽高，单位为 CSS px                                        |
| `deviceScaleFactor` | Playwright BrowserContext 使用的 DPR                                         |
| `isMobile`          | 是否启用 Chromium 移动布局行为                                               |
| `hasTouch`          | 是否启用触摸事件模拟                                                         |
| `fullPage`          | 是否截取整页；当前所有预设均为 `false`                                       |
| 理论 PNG 像素       | `viewport × DPR`；实际产物可能因 Chromium 缩放、取整或截图边界出现 1 px 差异 |

所有当前预设的公共行为：

```ts
{
  isMobile: true,
  hasTouch: true,
  fullPage: false,
  readySelector: '',
}
```

## 参数属性说明

| 属性     | 含义                                                           |
| -------- | -------------------------------------------------------------- |
| 机型映射 | 预设与具体设备或设备系列建立了代表性关联                       |
| 屏幕档位 | 用分辨率或屏幕尺寸表达的布局覆盖档位，不一定对应单一机型       |
| 工程推算 | 由物理分辨率、DPR 或样本现象推导的测试值，需要在真机上另行验证 |

## 在其他项目中使用

1. 将本文档和目标项目一起提供给负责布局的 Agent。
2. 要求 Agent 先检查项目现有组件、内容宽度、滚动结构和安全区处理。
3. 让 Agent 根据内容产生布局断点，然后使用本文档的 17 个视口验证，不要反过来直接将 17 个宽度写成媒体查询。
4. 如果需要自动截图，优先直接复用 Viewport Lab 的 `viewport-presets.ts`，避免手工复制造成参数漂移。

## 维护规则

1. `viewport-presets.ts` 是截图工具的参数事实来源，本文档是对外参考。
2. 新增视口前应确认它能覆盖新的布局档位，避免只因机型名称不同就增加重复视口。
3. 参数调整时应同步更新代码与本文档，并记录调整依据。
4. 取得真机验证结果后，应将对应参数从“工程推算”更新为“机型映射”，并保留验证来源。
